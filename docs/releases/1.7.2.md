nspawn 1.7.2 lets the package be built inside a systemd-nspawn machine.

## Fixed

- **The tests failed in a machine with a network of its own.** Building the
  package in a systemd-nspawn machine on a bridge failed its `check()`: such
  a machine has a tmpfs at the root of `/sys`, with sysfs mounted below it,
  and a test of `cp` took `/sys` itself for sysfs. The test finds proc and
  sysfs in the mount table now. Two other tests, one that needs procfs at
  `/proc` and one that needs devpts for a pseudo terminal, are skipped where
  those are missing instead of failing.
