nspawn 3.2.1 has packages for aarch64, and apt.nspawn.org and rpm.nspawn.org serve them.

## Added

- **Packages for aarch64**, experimental: `nspawn_3.2.1-1_arm64.deb`,
  `nspawn-3.2.1-1.fc44.aarch64.rpm` and `nspawn-3.2.1-aarch64-linux.tar.gz`, built and
  unit-tested on an aarch64 host; the end-to-end suite runs on x86_64. The repositories
  serve them to Debian 13, Ubuntu 24.04, Fedora 44 and later releases on arm64, with the
  same files that add them on amd64; `nspawn-selinux` is the same noarch package for
  both. Arch Linux has no aarch64 package; the AUR recipe lists aarch64.

## Requirements

As for 3.0.0.
