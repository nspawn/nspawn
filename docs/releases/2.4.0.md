nspawn 2.4.0 gives a published port without a host port a free one of the host, picks
an image index's entry by the platforms the host runs, and reads more of the forms
`-p`, `--dns-search` and `--add-host` take.

## Breaking changes

- **`-p PORT` takes a free host port.** `-p 80` published the host's port 80; it now
  gets a free port of the host, as `-p :80` and `-p 0:80` do, and `nspawn port NAME`
  shows which. The machine keeps the port it got across its starts. `-p 80:80`
  publishes the host's port 80. The bus's `publish` reads the same forms. A machine
  made earlier keeps the ports in its record.

## Changed

- **Image indexes** give the entry of the best platform the host runs: amd64 then 386,
  arm64 from the CPU's variant down to v8 and then 32-bit arm, arm from the CPU's
  variant down to v5; the first of equals. An amd64/v2 entry listed ahead of v1 is
  passed over, and an index of 386 images on amd64 or of arm images on arm64 is pulled.
  Entries that name no platform are tried last, in the index's order: the first whose
  config gives a platform the host runs is taken, before any layer comes down. When
  none fits, the error lists the platforms the index has.
- **`-p`:**
  - a host range with one container port (`-p 8000-8010:80`) takes the first free
    port of the range, and a container range alone (`-p 80-82`) a free host port for
    each;
  - the long form, `published=8080,target=80,protocol=udp,host_ip=127.0.0.1`, `target`
    the only one required;
  - the protocol in any case, an empty one being tcp;
  - an IPv6 host address without brackets (`-p ::1:8080:80`), an IPv4 one in brackets
    and an empty one, which is every address.
- **`--dns-search`** takes a domain of up to 254 characters, with a letter among its
  labels; a trailing dot is dropped and `.` stands for no search domain. An all-digit
  domain is refused.
- **`--add-host`** takes any name without colons, whitespace or control characters
  (`under_score.name`), and an IP in brackets.

## Requirements

As for 2.0.0.
