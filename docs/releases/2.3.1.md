With nspawn 2.3.1 the packages are on apt.nspawn.org and rpm.nspawn.org, and the deb
leaves the auto-update timer as it was across an upgrade.

## Packages

- **apt.nspawn.org** for Debian 13 or later and Ubuntu 24.04 or later (amd64):

  ```
  sudo curl -fsSLo /etc/apt/sources.list.d/nspawn.sources https://apt.nspawn.org/nspawn.sources
  sudo apt update
  sudo apt install nspawn
  ```

- **rpm.nspawn.org** for Fedora 44 or later (x86_64):

  ```
  sudo curl -fsSLo /etc/yum.repos.d/nspawn.repo https://rpm.nspawn.org/nspawn.repo
  sudo dnf install nspawn
  ```

Both keep the last five releases and are signed with the Ed25519 key
`1294612AB2DC4AE2F6118240FC5E133778B4B3B3`.

## Fixed

- **An upgrade of the deb leaves `nspawn-auto-update.timer` running.** It stopped the
  timer and nothing started it again until the next boot.

## Requirements

As for 2.0.0.
